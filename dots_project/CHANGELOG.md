# DOTS — История изменений

## v5.6

### Gameplay
- **Игры с призовым фондом** — при создании игры можно установить ставку (не более 50% от баланса). Победитель забирает весь банк, при ничьей ставки возвращаются
- **ИИ-атака** — бот теперь атакует вражеские клетки, если у него не осталось свободных клеток для размножения
- **Отображение призового фонда** — в HUD игры под балансом монет теперь показывается текущий банк

### UI / Интерфейс
- **Новый логотип на прелоадере** — буквы DOTSs идут по убыванию размера, снизу добавлены горизонтальная и наклонная линии (незавершенный треугольник)
- **Новый значок DTs** — золотое кольцо с выступающим за края текстом (используется в HUD и в рейтинге)
- **Рекламная заглушка** — каждые 20 туров появляется модальное окно на 90% экрана с возможностью закрыть; предусмотрено место для вставки кода Яндекс.Рекламы
- **Удаление игры в лобби** — создатель может удалить игру (красный крестик), если к ней ещё никто не присоединился; ставка при этом возвращается

### Лобби
- **История игр** — добавлен столбец с количеством туров
- **Глобальный рейтинг** — добавлен столбец с количеством побед

### Bugfixes
- **AI-Attack** — исправлен расчёт силы при атаке ИИ (теперь учитывается сила атакующей клетки, а не константа 1)

## v5.5

### Bugfixes
- **Черный экран при создании/входе в игру** — исправлен баг CSS (отсутствовало правило `display: block` для `#lobby-screen.active`), из-за которого экран ожидания игроков оставался скрытым
- **Острые углы у контура территории** — исправлен баг дублирования первой и последней точки в `buildContour`, из-за которого при сглаживании срезались углы (появлялись прямые линии)

### UI / Интерфейс
- **Кастомные окна подтверждения** — системный `confirm()` заменен на стилизованные модальные окна при нажатии «Сдаться» и «Выйти в лобби»
- **Редизайн щитка силы** — щиток стал меньше и теперь идеально вписан в окружность точки; внутри щитка добавлен кружок цвета игрока, вокруг которого центрирована цифра

## v5.4

### Gameplay
- **«Отсутствующий» игрок** — после 3 пропущенных туров подряд игрок получает метку «🚫 отсутствует»; его больше не ждут (тур заканчивается без него); если он вернётся — `missed_turns = 0` и продолжает играть
- **Победа по единственному активному** — если на карте остались клетки только у одного игрока — он побеждает
- **Убрано поражение за 3 пропуска** — раньше 1v1 заканчивалась победой активного; теперь игрок просто переходит в «отсутствует»

### Визуал
- **Разлиновка поля** — видна только при zoom ≥ 2.5×; при 3× едва заметна, при 8× — тонкая сетка (α до 0.10)
- **Заливка массы** — плотнее (α 0.52 вместо 0.26); точки под ней просвечивают, но территория явно очерчена
- **Прелоадер** — 2.5 секунды вместо 5

### UI
- **Метка «отсутствует»** в списке игроков (оранжевый бейдж)
- **Таймер grace** показывается только до метки absent (не дублируется)
## v5.3

### Gameplay
- **Длительность тура = 60 секунд** (было 180)
- **Разлиновка поля** — стала в 2× тоньше и деликатнее
- **Зум-порог разлиновки** — появляется с zoom 1.2 (было 0.8), при максимуме — тонкая сетка
- **Анимация размножения** — всегда от родителя (сервер передаёт `action_from`)

### HUD / интерфейс
- **Прелоадер при входе в игру** — 5 секунд чёрный экран с DOTS и спиннером
- **Крупнее монеты, тур, ходы** — увеличен шрифт в углах поля
- **Всплывающие сообщения** — под счётчиком клеток и % поля (были над ним)
- **Кнопки тех-панели** — текстовые: 📋 В лобби / 🏳️ Сдаться / 🎯 К моим точкам (откат к v5.1)
- **Кнопка звука** — справа сверху, иконка 🔊/🔇

### Лобби
- **Layout 40% / 30% / 30%** — активные игры / история / рейтинг
- **Заголовки по центру**
- **Кнопка «🔄 Вернуться в игру»** — крупнее и с текстом
- **Не пишется «None»** в названии игры, если его нет
- **История** — дата + время окончания

### Сообщения
- **«присоединился игрок …»** — показывается в зоне важных сообщений
- **«осталось менее 20% поля»** — новая подсказка (порог 80% занятых клеток)
- **Предупреждение за 10 сек** до конца тура — если не все ходы сделаны
- **Сообщение о завершении** — «🏆 Имя побеждает! Вы получаете +N DTs» (без ELO, без промежуточных цифр)

### Логи
- Показывают **только текущую игру** — при входе в новую игру лог очищается
- Максимум **12 записей** (без скролла)
