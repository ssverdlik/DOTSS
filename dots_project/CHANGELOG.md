# DOTS — История изменений

## v6.2

### Профиль и аккаунт
- **Модальное окно профиля** — размер 90% экрана, открывается кликом по имени или через кнопку «👤 Мой профиль». Содержит крупный ELO, полную статистику (DTs, матчи, победы, winrate) и историю последних 30 завершённых матчей.
- **Публичные профили** — клик по имени любого игрока в рейтинге открывает его публичный профиль (без управления аккаунтом). Имена в списке рейтинга теперь кликабельны.
- **Смена и установка пароля** — из профиля. Пользователи, вошедшие только через Яндекс, могут задать пароль и впоследствии входить по логину. При смене — проверка текущего пароля.
- **Выход из аккаунта** — кнопка «🚪 Выйти из аккаунта» прямо в профиле (с предварительным подтверждением). Модалка подтверждения теперь всегда открывается поверх профиля (исправлен `z-index`).

### Привязка аккаунтов
- **Привязка Яндекса к существующему аккаунту** — если вы зарегистрировались через логин/пароль, теперь можно привязать Яндекс в профиле и входить в один клик.
- **Отвязка Яндекса** — доступна из профиля. Защита: если у аккаунта нет пароля, отвязка заблокирована (чтобы не потерять доступ).
- **Передача токена через URL** — при переходе на `/api/auth/yandex?link=1&token=...` токен передаётся в query-параметре, что позволяет привязывать Яндекс без предварительного `fetch`.
- **Обработка конфликтов** — если Яндекс уже привязан к другому аккаунту, показывается ошибка.

### Аватары
- **Извлечение аватара из Яндекса** — поддержка всех трёх форматов ответа API:
  - `default_avatar` (объект с URL);
  - `passport_avatars` (массив с размерами);
  - `default_avatar_id` (строка — собирается URL вручную через `https://avatars.yandex.net/get-yapic/{id}/islands-300`).
- **Всегда обновлять аватар при привязке** — если Яндекс вернул URL, он перезаписывает текущий (раньше срабатывало только для пустого аватара).
- **Fallback-аватар** — если аватар не задан, отображается стандартная SVG-иконка «человечек».
- **Аватары в рейтинге** — отображаются рядом с именем игрока (26px, круглые).

### API
- **`GET /api/me`** — добавлено поле `yandex_linked` (показывает, привязан ли Яндекс).
- **`POST /api/unlink_yandex`** — эндпоинт для отвязки Яндекса. Возвращает ошибку, если у пользователя нет пароля.
- **`GET /api/user_profile/<id>`** — публичный профиль игрока (без приватных полей).
- **`GET /api/user_matches/<id>`** — история матчей любого игрока (для публичных профилей).

### OAuth Яндекс
- **Scope расширен** — добавлен `login:avatar` для доступа к расширенным размерам аватара (в дополнение к `login:email`, `login:info`).
- **Обработка callback** — обновлён парсинг ответа `/info` для надёжного извлечения аватара во всех случаях.
- **Редирект после привязки** — на `/?yandex_linked=1`, после чего фронт показывает уведомление «Яндекс успешно привязан».

### UI/UX
- **Уведомления после OAuth** — при возврате с привязки Яндекса показываются сообщения об успехе или ошибке (`already_linked`, `need_login`).
- **Поля пароля обёрнуты в `<form>`** — убраны предупреждения Chrome/Edge в консоли (`Password field is not contained in a form`, `Password forms should have username fields`).
- **Скрытое поле `username`** в форме смены пароля — для корректной работы менеджеров паролей.
- **Кнопки «Отвязать» и «Привязать Яндекс»** — в стиле фирменных цветов Яндекса (белая «Я» в красном круге).
## v6.1

### Аутентификация
- **Вход через Яндекс** — новый способ авторизации в один клик. Реализован через прямой OAuth-обмен (без `django-allauth`), полностью совместим с существующей кастомной моделью `User`.
- **Кнопка Яндекс.Входа** — с фирменным логотипом (белая «Я» в красном круге) на экране авторизации.
- **Уникальность аккаунтов** — `username` и `yandex_id` защищены ограничением `unique=True`. При совпадении ника с существующим аккаунтом автоматически генерируется суффикс (`ivan_1`, `ivan_2`).
- **Токены после OAuth** — при успешном входе через Яндекс создаётся стандартная `Session` и токен передаётся клиенту через URL (`?yandex_token=...`), после чего автоматически подхватывается клиентом и убирается из адресной строки.

### Профиль и аккаунт
- **Аватары из Яндекса** — при входе через OAuth подтягивается `default_avatar` пользователя и сохраняется в `User.avatar_url`. Отображается в глобальном рейтинге, в профиле и в меню.
- **Fallback-аватар** — если у пользователя нет аватара (обычная регистрация), используется встроенная SVG-иконка «человечек».
- **Модальное окно профиля** — размер 90% экрана, доступно по клику на имя или через кнопку «👤 Мой профиль». Содержит:
  - Крупный ELO-рейтинг;
  - Статистику: глобальные DTs, сыгранные матчи, победы, winrate в процентах;
  - Историю последних 30 матчей (дата, размер карты, захваченные клетки, победа/поражение).
- **Управление паролем**:
  - Пользователи, вошедшие через Яндекс, могут **задать пароль** и в дальнейшем логиниться стандартным способом;
  - Пользователи с паролем могут **сменить** его (с проверкой текущего);
  - Валидация: новый пароль не менее 4 символов, повтор должен совпадать.
- **Выход из аккаунта** — доступен как на главном экране (кнопка «🚪 Выйти»), так и внутри профиля (с предварительным подтверждением).

### API
- **`GET /api/me`** — добавлено поле `has_password`, показывающее, установлен ли у пользователя пароль.
- **`POST /api/change_password`** — эндпоинт для смены/установки пароля (требует `old_password`, если пароль уже есть).
- **`GET /api/my_matches`** — возвращает последние 30 завершённых матчей текущего пользователя со статистикой.
- **`GET /api/leaderboard`** — добавлено поле `avatar_url` для каждого игрока.
- **`POST /api/auth/yandex`** и **`/api/auth/yandex/callback`** — эндпоинты OAuth-флоу.

### Модели
- **`User.yandex_id`** — `CharField(max_length=64, unique=True, null=True, blank=True)` — привязка к Яндексу.
- **`User.avatar_url`** — `URLField(max_length=500, null=True, blank=True)` — ссылка на аватар.
- **`User.password_hash`** и **`User.salt`** — теперь могут быть `NULL` (для пользователей, вошедших только через Яндекс).

### Технические детали
- **`requests`** — добавлен в `requirements.txt` для OAuth-запросов к Яндекс.API.
- **`YANDEX_CLIENT_ID`**, **`YANDEX_CLIENT_SECRET`**, **`YANDEX_REDIRECT_URI`** — настройки в `settings.py`.
## v6.0

### Игровой процесс и экономика
- **Экономика при входе в игру** — при присоединении к активной игре с призовым фондом с игрока мгновенно списывается взнос, а общий банк пополняется. Визуально призовой фонд обновляется у всех участников сразу.
- **Мгновенное появление на поле** — при входе в активную игру точка нового игрока спавнится и отображается у всех участников немедленно, без ожидания следующего тура.
- **Защита новичков** — если игрок присоединился в середине тура, ему не начисляется штраф «отошел» за пропуск хода (он получает возможность сделать ход в следующем туре).
- **Синхронизация времени** — сервер теперь передает точное время `time_left` до конца тура. Клиент корректно синхронизирует таймер, исключая ситуации, когда после переподключения времени оставалось больше, чем у остальных.
- **Остановка таймера** — при завершении игры таймер мгновенно останавливается и показывает `0:00`.

### Статусы и уведомления
- **Статус «Отошел»** — плашка теперь появляется сразу (снимается бледность) и снимается при первом же клике игрока по любой клетке (сервер мгновенно рассылает обновление).
- **Сдавшиеся игроки** — больше не получают статусы «отошел» или «отсутствует» (у них и так висит флажок), а также их вход/выход в лобби не засоряет лог игры.
- **Стилистика** — плашка «отошел» теперь без рамки, в том же стиле, что и «отсутствует».
- **Сообщения** — при заходе в игру пишется «Новый игрок присоединился» (убран смайлик-рука, исправлена путаница с «вернулся»).

### Интерфейс и мобильная адаптация
- **Мобильный звук** — исправлена разблокировка `AudioContext` на iOS (теперь звук работает после первого касания экрана).
- **Слайдер ставки на iOS** — исправлена проблема с захватом пальца (увеличен размер ползунка и убран конфликтующий `touch-action`).
- **Мобильный скролл** — исправлен скролл на главном экране, порядок панелей изменен: Активные игры → Рейтинг → История.
- **Рейтинг** — иконки кубка и DTs увеличены до 32px для лучшей читаемости.
- **История игр** — список обрезается до 15 последних записей (без скролла).
- **Кнопка входа** — в списке активных игр текст «Войти» заменен на «Присоединиться».
## v5.9

### Архитектура и оптимизация
- **Разделение монолитного `index.html`** — файл (размером около 3000 строк) разбит на 6 логических частей для удобства поддержки и кэширования браузером:
  - `index.html` — чистая HTML-разметка
  - `css/style.css` — все стили
  - `js/icons.js` — SVG-иконки
  - `js/api.js` — API-запросы и звуки
  - `js/pixi_game.js` — вся графическая логика (PixiJS)
  - `js/main.js` — интерфейс, WebSocket и рендеринг панелей
- **Настройка статики Django** — добавлены `STATIC_ROOT` и `STATICFILES_DIRS` в `settings.py` для корректной работы команды `collectstatic`.

### Визуал (UI/UX)
- **Замена эмодзи на SVG** — все текстовые смайлики (💰, ⚡, 🏆, 🏳️, 🤖 и т.д.) заменены на кастомные векторные иконки. Они стали крупнее, четче и стилистически едиными с интерфейсом игры.
- **Иконки игроков** — в лобби и списке игроков теперь отображаются иконки "Человек" и "ИИ-робот" вместо текстовых бейджей.
- **Новые иконки в меню** — добавлены иконки к кнопкам (В лобби, Сдаться, Правила), к разделам справки (Цель, Размер, Туры, Управление) и к валюте (DTs).

### Мобильная адаптация (Mobile First)
- **Адаптивный интерфейс** — добавлены `@media` запросы для экранов до 768px.
- **Игровой экран на смартфонах** — интерфейс перестраивается вертикально: игровое поле занимает ~60% высоты сверху, панель управления — ~40% снизу (кнопки и лог становятся компактнее).
- **Меню и лобби** — сетки на мобильных устройствах перестраиваются в один столбец для удобного скролла.
- **Сенсорное управление** — добавлено свойство `touch-action: none;` на игровое поле, чтобы при перетаскивании карты не скроллилась вся страница. Запрещен случайный зум страницы пальцами (`user-scalable=no`).

### Багфиксы и улучшения (из прошлых итераций)
- **Модальное окно победы/поражения** — теперь четко указывает причину завершения игры (например, "Захвачено 70% площади карты", "Соперник сдался", "Все противники уничтожены").
- **Очередь WebSocket-сообщений** — клиент обрабатывает пакеты строго по очереди, что исключает пропажу анимации первого хода ИИ.
## v5.8

### Gameplay
- **Исправление логики победы** — текст в справке «Как играть» приведен в соответствие с реальным кодом: победа присуждается при захвате **70% от всей площади карты** (а не от занятых клеток)
- **Исправлена блокировка ИИ** — бот больше не «зависает» и не проигрывает досрочно, если его окружили. Теперь ИИ может атаковать вражеские клетки, если у него нет свободных ходов для размножения
- **Запрет выбора клеток без ходов** — если у игрока закончились ходы в текущем туре (0 из 3), клик по своим клеткам больше не подсвечивает их (аналогично тем, что уже сходили)
- **Принудительный первый ход ИИ** — бот гарантированно делает ход в 1-м туре, а не со второго

### Визуал и UI
- **Новый логотип DOTSs** — убраны линии, увеличен перепад размеров букв (от огромной D до маленькой s)
- **Новый значок DTs** — переработан в золотой круг с белыми линиями и жирным шрифтом с засечками
- **Масштабирование значков** — иконки DTs увеличены на 50% везде (в HUD, рейтинге, профиле, логах, кнопках, модальных окнах и справке)
- **Очистка лога** — при переходе в новую игру старый лог больше не отображается (исправлено дублирование при получении пакета `joined`)

### Лобби и интерфейс
- **Скролл в списках** — активные игры, история и рейтинг ограничены высотой экрана и имеют аккуратный скролл
- **«Липкий» рейтинг** — если вы находитесь ниже Топ-20, ваша позиция закрепляется внизу с разделителем `****`
- **Ставка ползунком** — при создании игры с призовым фондом используется слайдер с отображением точного значения
- **Показ взноса** — в списке активных игр отображается вступительный взнос и общий банк

### Багфиксы
- **Ошибка 404 при удалении игры** — исправлен маршрут в `urls.py` (добавлен слэш)
- **Гонка данных WebSocket** — клиент теперь обрабатывает сообщения последовательно (через очередь), что предотвращает пропажу первого хода ИИ при загрузке
- **Контур территории** — убраны дублирующиеся точки, из-за которых срезались углы (теперь плавные скругления)
- **Щиток силы** — идеально вписан в окружность, цифра обведена кружком цвета игрока

## v5.4

### Gameplay
- **«Отсутствующий» игрок** — после 3 пропущенных туров подряд игрок получает метку «🚫 отсутствует»; его больше не ждут (тур заканчивается без него); если он вернётся — `missed_turns = 0` и продолжает играть
- **Победа по единственному активному** — если на карте остались клетки только у одного игрока — он побеждает
- **Убрано поражение за 3 пропуска** — раньше 1v1 заканчивалась победой активного; теперь игрок просто переходит в «отсутствует»

### Визуал
- **Разлиновка поля** — видна только при zoom ≥ 2.5×; при 3× едва заметна, при 8× — тонкая сетка (α до 0.10)
- **Заливка массы** — плотнее (α 0.52 вместо 0.26); точки под ней просвечивают, но территория явно очерчена
- **Прелоадер** — 2.5 секунды вместо 5

### UI
- **Метка «отсутствует»** в списке игроков (оранжевый бейдж)
- **Таймер grace** показывается только до метки absent (не дублируется)
